# Exception Handling

**Document ID:** POL-EXC-004
**Owner:** Governance
**Version:** 1.0
**Last reviewed:** 2019-11-02

---

## 1. Principle

Every exception to a published policy must be **recorded, owned and dated**.
An exception with no end date is a policy change that nobody approved.

## 3. Requesting an exception

Email Governance with: the policy, the reason, the scope, and an end date.
An exception without an end date will not be approved.
