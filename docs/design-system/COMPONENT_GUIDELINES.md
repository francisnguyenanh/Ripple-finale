# Component guidelines

Implemented shared components. Planned components are not listed until they exist and have a real caller.

| Component | File | Purpose and contract |
|---|---|---|
| `Button` | [button.tsx](../../frontend/src/components/ui/button.tsx) | `variant` primary/secondary/ghost/danger; `size` sm/md/lg (default md); `type` defaults to `button`; `asChild` for links. A disabled action needs a visible reason next to it. |
| `Modal` | [dialog.tsx](../../frontend/src/components/ui/dialog.tsx) | Native `<dialog>` (CSP-safe), `side` center or drawer, restores focus on close. |
| `Tabs*` | [tabs.tsx](../../frontend/src/components/ui/tabs.tsx) | Radix tabs with token styling. |
| `Tip` | [tooltip.tsx](../../frontend/src/components/ui/tooltip.tsx) | Short supplementary label only; never the sole place for a required fact. |
| `Card`, `Muted`, `Callout` | [bits.tsx](../../frontend/src/components/bits.tsx) | Surface with optional title; secondary text; boxed notice with tone info, warn, danger or wait (warn / danger / wait carry a 4 px left marker, info a plain frame). SCN-13 structure: with a header (`title`, `aside`, `eyebrow`, `description` or `meta`) the card is a header strip (`px-4 py-3`, bottom rule) and a body (`p-4`, or none with `flush`); without a header one padded body; never clips its content. SCN-01 `Card` props, all optional: `eyebrow` (only when it adds information the title lacks), `description` (one sentence), `meta` (a scoped server timestamp or scope note, never the render clock), `flush` (no body padding; header separated by a border, for a table, list or canvas), `accent`, `level` (2 or 3). Consumers: My work (flush), catalog. |
| `EmptyState` | [bits.tsx](../../frontend/src/components/bits.tsx) | SCN-11. A state with no rows said for what it is: `none` (nothing exists as far as this read shows), `no-match` (a filter hides everything: offer to clear it, scope kept), `error` (the read failed; never "nothing here"; a retry when the route allows), `partial`, `denied` (says nothing about existence). The reason comes from what is known; `action` is an allowed next step of the feature (a link or a local control, never a mutation or a paid call). `data-empty` carries the kind. Consumers: My work (empty, group no-match), DataTable defaults, Explorer graph no-match, Sources no import, History no versions. |
| `Eyebrow`, `Datum`, `ACCENT_CLASS` | [bits.tsx](../../frontend/src/components/bits.tsx) | SCN-01. `Eyebrow`: 12 px uppercase kicker. `Datum`: one labelled fact with the value weighted above the label; a missing value shows `unknown` ("Not recorded" by default, "Unavailable" for a failed read), never 0 or blank; spans only, so it can sit in a button. `ACCENT_CLASS`: the selective left marker (primary = your step, warning = blocked / partial, danger, success, info); the text must say the same. Consumers: TaskFrame header, Overview counts. |
| `DataTable`, `sortRows` | [data-table.tsx](../../frontend/src/components/ui/data-table.tsx) | SCN-09. Typed columns (`id`, `header`, `cell`, optional `sortValue`, `essential`, `align`), stable `rowKey`, `rowProps` for test ids, explicit `state` (loading / ready / empty / error / partial: an error is never an empty table), `density` comfortable (default) or compact. Loaded mode only: optional client sort uses typed values (numbers as numbers, missing last, original order as tie-break) and `scope` says it covers the loaded rows; no server paging control exists until an API provides cursor and coverage. Under 768 px rows become labelled stacks (`.rp-stack` in index.css), no column dropped. `flush` (SCN-15): inside a flush `Card` the header band (`--surface-2`, `--border-strong` rule) and row rules reach the panel edges, the first / last cells line up with the panel header's 16 px, row hover is a light tint; loading / empty / error keep their own padding; cell padding and focus rings are kept. Consumers: My work groups, History versions (both flush), History version files (inspector, not flush). Tested in `data-table.test.ts`; edges measured in `test_scn_polish_browser` / `test_scn_inspector_browser`. |
| `HowItWorks` | [bits.tsx](../../frontend/src/components/bits.tsx) | Routine explanation (walkthroughs, repeated definitions) collapsed under "How this works" (native `details`: keyboard and touch). Never holds a blocker, the consequence of the next action, a paid-use note or a stale / partial warning; those stay visible beside the action. Consumers: Sources update panel (`refresh-how`), Questions knowledge summary (`knowledge-how`), what-if simulation (`sim-how`). |
| `StatePill` | [bits.tsx](../../frontend/src/components/bits.tsx) | Domain state: business label in Business view, raw state in Technical view; `data-state` always carries the machine value. Tone comes from `stateTone` in [stateDisplay.ts](../../frontend/src/lib/stateDisplay.ts); an unknown token is neutral. A label longer than a short status wraps instead of being clipped; pass the full reason as `detail` or as adjacent text. `RUNNING` shows a small decorative dot that pulses only when motion is allowed; the label itself never animates, so its contrast holds in every frame. |
| `StatusBadge` | [StatusBadge.tsx](../../frontend/src/components/StatusBadge.tsx) | Generic loading, empty, queued, running, waiting, stale, partial, failed, success, info or simulated badge: icon plus text. A `success` label should name its scope. |
| `Field`, `TextInput`, `TextArea`, `Select` | [bits.tsx](../../frontend/src/components/bits.tsx) | Labelled controls (`min-h-10`, `bg-bg`). `Select` is the shared native select; give it a visible label through `Field` or an `aria-label`. |
| `Tech`, `TechField`, `Fingerprint`, `Name`, `Path`, `ClaimLabel`, `ClaimTitle` | [bits.tsx](../../frontend/src/components/bits.tsx) | Business and Technical views of the same fact; technical-only content is not rendered in Business view. |
| `Denied` | [bits.tsx](../../frontend/src/components/bits.tsx) | Refused read: plain panel, announces the refusal once, reveals nothing. |

## Decision and evidence presentation (`frontend/src/components/decision/`)
| Component | File | Purpose and contract |

| `OriginTag`, `OriginSection` | [Origin.tsx](../../frontend/src/components/decision/Origin.tsx) | Where content comes from: `origin` `ai` (dashed border, sparkle icon, "AI"), `source` (document icon) or `engine` (gauge icon); an unknown origin is neutral (`originDisplay` in [originDisplay.ts](../../frontend/src/components/decision/originDisplay.ts), tested in `originDisplay.test.ts`). `OriginSection` keeps the caller's `aria-label`, test id and `data-status`, adds `data-origin`. | `TrustStateSummary` | [TrustStateSummary.tsx](../../frontend/src/components/decision/TrustStateSummary.tsx) | Independent completion axes side by side, never merged into a score or a green badge. Other specialist components (semantic delta, findings triage, provenance inspector, simulation outcome, AI interpretation preview) are added only together with their first real consumer and are documented here when they exist.

## Rules for these components
- Props carry presentation and callbacks only. No component fetches or mutates on mount.
- Keep `data-testid` and `data-state` stable; tests rely on them.
- Anti-patterns: a second modal implementation, a new status-to-colour map, a custom pill for an instruction-length sentence, a native select styled with an undefined token.

## Adding or changing a component
Update the table above, add a real example in the consuming feature, and extend the unit test that covers the display mapping (see [stateDisplay.test.ts](../../frontend/src/lib/stateDisplay.test.ts)). Deprecations are listed here with the replacement and the remaining callers.

Deprecated: a raw `<select>` with local classes. Replacement: `Select` from `bits.tsx`. Eight raw selects remain (listed as `E03` legacy debt in `frontend/design-system-policy.json`: Analysis and Apply stages, Harbor, Support workspace section; the business change review migrated with EUI-06, the shell workspace picker with SCN-05); migrate each with the package that owns the page, then delete its policy entry. New raw selects are rejected by `npm run check:design`.
