# Final build: claims, evidence, limits

A claim without a row here is not made for the Final build. Evidence is the test code in this repository (database-backed suites run on a disposable PostgreSQL with synthetic
model stubs) plus the contracts and the quality plan; "self-check" means the project's own runs, never human acceptance. The Phase 1 rows stay in [`CLAIMS_EVIDENCE_LIMITS.md`](CLAIMS_EVIDENCE_LIMITS.md).
