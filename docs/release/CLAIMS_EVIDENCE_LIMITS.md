A claim without a row here is not made. Evidence ids are job/revision ids kept on the server; test names are in this repository. "Self-check" means an agent-run check, not human acceptance.

## Not claimed
That a change whose re-analysis has used up its provider attempts can be retried or completed (it cannot, by decision: row 11); that Ripple reads Word, PDF, PowerPoint or any format outside the supported list (it refuses them per file); that the held-out AI-quality evaluation passed (its targets were not met: relation recall 0/44, conflict recall 0/24, extraction precision 37/100; see [`../evaluation/HELD_OUT_EVALUATION.md`](../evaluation/HELD_OUT_EVALUATION.md)); that the result was a deliberate design choice (the evaluation does not separate the causes); "Phase 1 complete"; "absolute" or "enterprise-grade" safety; Harbor "complete"; AI better than a non-AI baseline; accuracy figures; that the guide's exact request passes draft-to-proposal; that the recorded case reached final acceptance; any pass of the held-out AI-quality criteria; a hard cap on infrastructure cost; that quotas (12 jobs per account, 80 AI jobs in total) are guaranteed (the shared provider cap can stop earlier).

## Open defects and known limits
**Open defects:** none known. A test that failed earlier (`test_sim_analysis_budget`) was a test-layout drift, not a product fault: the per-workspace concurrency check runs before the budget reservation by design, so the test now covers the two refusals separately (`concurrency_limit` at the limit; `budget_exceeded` when a slot is free but the budget is not), each with no reservation, charge or provider call. `docs/runbooks/pitch_budget_config.yaml` is a template (total cap 12.82 USD); the live provider cap (8.30 USD) is set in the cloud configuration, not in that file.

**Known limits:** numeric YAML values only; scope sentences recorded, not enforced; one sample system; no hard cap on web compute; the held-out AI-quality targets were not met and were not re-run on the current build; scenario A is only partly one continuous run (see [`SCENARIO_STATUS.md`](SCENARIO_STATUS.md)); the four-role case's final acceptance is pending; licence is proprietary, Competition Evaluation Only (`LICENSE`), not open source; no parser exists for source types outside the supported list (they are refused per file); no automatic recovery of a re-analysis that used all its attempts (a person chooses Request changes or Reject); operator-only inputs (cloud manifest, cloud operator tooling) are not shipped, so the tests that read them are skipped with a stated reason; browser tests need Playwright and Chromium (without them they are skipped).
